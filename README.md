# Investa - Aprenda a Investir

Plataforma educacional que ensina voce a investir do zero. Aprenda, acompanhe o mercado e planeje seu futuro financeiro.

## Funcionalidades

- **Trilha de Aprendizado**: Cursos do basico ao avancado com quizzes interativos
- **Painel de Mercado**: Cotacoes simuladas com atualizacao automatica
- **Simulador**: Pratique com dinheiro ficticio
- **Professor IA**: Tire duvidas sobre investimentos
- **Objetivos**: Defina metas e simule cenarios
- **Alertas**: Notificacoes configuraveis

## Tecnologias

- Next.js 14 + TypeScript
- Tailwind CSS
- React (App Router)

## Como rodar

```bash
npm install
npm run dev
```

Acesse http://localhost:3000
